# Subscription Billing Support Casebook

Realistic billing support cases, each documented from customer symptom
to resolution. Written to practice the skills of a Technical Support
Engineer at a subscription billing company.

## Cases
1. Charged twice after upgrade
2. Webhook not received


## How each case is structured
Symptom → Investigation → Root cause → Fix → Customer reply → Escalation

## Tools used
Stripe test mode, Postman, webhook.site, public billing docs
